## 6. Проверка возможности запуска

Приложение не может быть запущено в текущем окружении по следующим причинам:

1. **Python/pip не могут выполниться** — рабочая директория заблокирована правами доступа Windows (ошибка `SetNamedSecurityInfoW`, Win32 5). Необходимо исправить права на папку `D:\Vibecode\aidd-topic03-homework`.
2. **PostgreSQL не запущен** — требует `docker-compose up` для сервиса `db`.
3. **Redis не запущен** — требует `docker-compose up` для сервиса `redis`.
4. **TINKOFF_TOKEN не задан** — все вызовы к Tinkoff Invest API будут падать.

Для запуска необходимо:
1. Исправить права доступа к рабочей директории
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить PostgreSQL и Redis: `docker-compose up -d`
4. Применить миграции: `python manage.py migrate`
5. Создать суперпользователя: `python manage.py createsuperuser`
6. Задать `DJANGO_SECRET_KEY` и `TINKOFF_TOKEN` в переменных окружения
7. Запустить сервер: `python manage.py runserver`
8. Для фонового обновления цен: запустить Celery Beat и Celery Worker
