## 3. Проблемы каждого агента (практический опыт)

### 3.1 Проблемы Cline

1. **База данных**  
   Долго не удавалось настроить стабильную работу с БД (миграции, путь/доступ, запуск). Потребовалось **много дополнительных итераций**. **В итоге Cline разобрался и починил** БД — контур стал рабочим, но цена по времени высокая.

2. **Модуль Tinkoff / T-Invest**  
   **Не разобрался с подключением SDK**, не довёл установку и импорт клиента API до рабочего состояния. Реальные котировки через официальный клиент с Cline на этом ДЗ **не заработали**.

3. **Прочие**  
   - Неполный входной набор файлов (manage.py, user, requirements) — восстанавливал в процессе.  
   - Сбои окружения pip/путей.  
   - Упрощение auth (username FBV вместо email-flow исходника).

### 3.2 Проблемы Nemotron 3.5 Super VL (free)

1. **Ограничения free-режима** — обрезка ответов, «continue», больше итераций.  
2. **Риск формальной готовности** — без «check + HTTP 200» отчёт может опережать проверку.  
3. **SDK** — нужно было явно указать актуальный install (`t-tech-investments`, `t_tech.invest`).  
4. **UI симулятора стратегий** слабее, чем у Cline.

---

## 4. Качество, автономность, эффективность

**Качество.**  
- Документы и FR — сильнее у **Nemotron**.  
- UI новой функциональности (strategies и др.) — заметнее у **Cline**.  
- БД: у Cline **итоговый успех после долгой отладки**.  
- Tinkoff SDK: у Cline **не закрыто**; у Nemotron — схема установки + demo.

**Автономность.**  
- Cline сам правил код и **в конце закрыл БД**, но только после затяжного цикла ошибок.  
- По Tinkoff автономия Cline **не сработала**.  
- Nemotron лучше держит план документов; для кода нужна приёмка.

**Эффективность.**  
- Cline: низкая эффективность на этапе БД (долго), но результат по БД положительный; по SDK — нулевая отдача.  
- Nemotron: время на free-лимитах, на анализе/FR стабильнее.

## 5. Преимущества и недостатки

### Cline
**+** Сильная генерация UI/кода фич; **БД в итоге починил**; удобен для правок в репозитории.  
**−** Очень долго отлаживал БД; **Tinkoff SDK так и не подключил**; слабее блок формальных FR.

### Nemotron 3.5 Super VL (free)
**+** ANALYSIS/FR; актуальный путь T-Invest + demo; структура сдачи.  
**−** Free-лимиты; слабее UI стратегий; нужен явный контроль запуска.

| Задача | Целесообразнее |

| Разбор кода и FR (№1–2) | **Nemotron** |

Для критериев «реальные котировки через SDK» результат Cline недостаточен; для «БД работает после модернизации» — достаточен после длительной доводки.

Код сдаётся в **двух ветках GitHub**; сравнение — по содержанию веток и проблемам выше.
